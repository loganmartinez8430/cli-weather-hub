# Terminal Weather CLI ⛅🌡️

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Curl Powered](https://img.shields.io/badge/Data-wttr.in-green.svg)](https://wttr.in)

Real-time, ultra-fast weather reports and atmospheric conditions right in your command line.

## Highlights
- 🌦️ **ANSI Icons**: Dynamic weather glyphs (sun, rain, snow, clouds).
- 🌡️ **Comprehensive Stats**: Real temperature, wind speed, and humidity.
- ⚡ **Instant Execution**: Lightweight single-file tool with no setup required.

## Usage
```bash
python weather.py Tokyo
python weather.py "San Francisco"
python weather.py London
```
